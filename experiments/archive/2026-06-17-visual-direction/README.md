# AgentDiligence visual direction archive — 2026-06-17

These are decision-support mockups from the AgentDiligence dark evidence homepage work. They are archived for design provenance, not linked from the live homepage.

All HTML pages include `robots: noindex,nofollow` because they are rough visual explorations, not canonical product pages.

## Archived experiments

- `visual-opportunities-mockups/` — Visual opportunity mockups: six candidate visuals for evidence, comparison, scope, Task Spec, trigger cards, and replay.
- `selected-visual-page-mockup/` — Selected page mockup: combined Evidence Packet anatomy, Task Spec primitive, and Replay timeline direction.
- `minimal-visual-options/` — Minimal visual options: A-F comparisons for reducing boxes-within-boxes around Task Spec/evidence.
- `spec-receipt-border-options/` — Spec receipt border options: border/capline alternatives; B capline was selected and shipped.

## Shipped outcomes from this batch

- The dark evidence direction remains the main homepage direction.
- The capline Task Spec receipt was selected and shipped.
- The stronger Evidence report section was selected and shipped.
- Vendor references were changed to text-only typography rather than logos/wordmarks.
