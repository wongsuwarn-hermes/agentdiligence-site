Spec receipt edge alternatives

Keep the slip. Lose the teeth.

The receipt/lab-slip metaphor is useful, but the sharktooth edge is too decorative. These variants keep the proprietary Task Spec feel with quieter, cleaner perimeter treatments.

Goal: preserve “locked document / evaluation slip” without making the artefact feel novelty, playful, or visually busy.

Same content, different edge language

Eight border treatments.

All options use the same receipt content so the comparison is about the edge style, not the information design.
